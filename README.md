# JARVIS-JS-🤖

A voice-controlled AI assistant, ported from my original Python project 
to JavaScript so it can run directly in the browser.

## 🔗 Live Demo
[Try JARVIS]()

> ⚠️ Requires Chrome or Edge (uses the Web Speech API). 
> Click "Start Listening" and allow microphone access.

## 📌 About The Project
JARVIS started as a Python desktop assistant with speech recognition, 
text-to-speech, Wikipedia lookups, web search, and app/website launching. 
Since a desktop app can't be demonstrated on the web, I rebuilt its core 
logic in JavaScript using the browser's native Speech Recognition and 
Speech Synthesis APIs — bringing the same assistant to life as a web app.

## 🎙️ What JARVIS Can Do
- Greets you based on the time of day
- Listens for voice commands and responds out loud
- Searches Google for any topic
- Looks up topics on Wikipedia and reads a short summary
- Opens common websites (YouTube, Gmail, Instagram, etc.)
- Tells you the current time
- Introduces itself when asked "who are you"

## 🗣️ Example Commands
- "What time is it"
- "Open YouTube"
- "Search [topic] on Wikipedia"
- "Who are you"
- "Goodbye"

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- Web Speech API (SpeechRecognition & SpeechSynthesis)
- Wikipedia REST API

## 🐍 Original Version
The original Python version used `speech_recognition`, `pyttsx3`, 
and `wikipedia` libraries with the same command logic.
